hpc

One command for the UniCal HPC cluster.

Submit Slurm jobs with sensible presets, watch the queue, sync files and read logs, straight from your own terminal.

Get started View on GitHub

Unofficial · open source · MIT

~/projects/my-model 
# copy the project to the cluster
$ hpc push

# a 2-hour job on a Small GPU slice, restartable
$ hpc submit small --time 02:00:00 \
    --requeue train.sbatch

# watch it, then read the output
$ hpc queue
$ hpc logs -f▍

The university VPN is required.

The cluster head node is reachable only through the university OpenVPN, which must be active every time you run hpc. The OpenVPN configuration is not distributed with this tool: request it through UniTicket.

Quick start

Three steps, then a five-second smoke test.

1

Upload your SSH key

Once, with the VPN on. The password is asked only this time.

ssh-keygen -t ed25519
ssh-copy-id YOUR_LOGIN@hpcgate.unical.it

2

Install the command

Clone the repository and link hpc on your PATH.

git clone https://github.com/paolaguarasci/hpc-unical
cd hpc-unical
ln -s "$PWD/bin/hpc" ~/.local/bin/hpc

3

Set your login

Kept in a git-ignored .env file.

cp .env.example .env
# edit: HPC_USER=your_cluster_login

Run the demo

$ hpc qos                                                 # which QoS may you use?
$ hpc push                                                # copy the project to the cluster
$ hpc submit tiny --time 00:05:00 templates/demo.sbatch   # submit the smoke test
$ hpc queue                                               # PENDING → RUNNING → COMPLETED
$ hpc logs                                                # read the output

Commands

CommandWhat it does
hpc submit CLASS --time T SCRIPTSubmit a batch script with the preset of the class; --booked, --requeue, --push, --free, --cpus, --mem are optional; options after -- go to sbatch unchanged (e.g. --array)
hpc run CLASS --time T [--pull PATH]… SCRIPTPush, submit, wait for the job and pull each --pull path if it completed
hpc sweep CLASS --time T --params FILE SCRIPTJob array with one task per line of a parameter file; --parallel N caps the tasks running at once
hpc statusRunning and pending jobs and the last job, in one line
hpc queue [-w [SECONDS]]Your pending and running jobs, plus the last 24 hours of history; -w refreshes the view live
hpc topInteractive view of the cluster and of your jobs: usage bars, live output, history; requires uv
hpc qosQoS associations granted to your account
hpc pushSync the current directory to the cluster; honours .gitignore and .hpcignore, never deletes
hpc pull PATH…Fetch the named files from the cluster project directory
hpc logs [ID] [-f]Show or follow a job's output
hpc cancel IDCancel a job
hpc shell CLASS --time TInteractive shell on a compute node, with the preset of the class
hpc tunnel ID PORTForward a local port to a server run by a job
hpc serve CLASS --time T SERVICERun jupyter, comfy, ollama, vllm MODEL or tensorboard (or your own server with --cmd) as a job and open it on localhost; Ctrl-C cancels the job
hpc bench CLASS --time T MODELBenchmark vLLM on a GPU class in one job: output tokens per second, time to first token and time per token
hpc setup [ollama] [comfy] [vllm] [tensorboard]Check ollama, ComfyUI, vLLM and TensorBoard on a compute node and install what is missing, software only
hpc model comfy URL --to KINDDownload ComfyUI models on the cluster, in one compute job (several URLs, a --to folder for those that follow) (hpc model ollama NAME for an Ollama model); never overwrites, refuses when space is short
hpc model list [comfy|ollama]List the downloadable ComfyUI models (about 500) and the Ollama models installed, marking those already present; --type, --filter and --urls are optional
hpc model template NAMEDownload all the models that a ComfyUI template declares, with no URL to copy; hpc model template list shows which are present, hpc model comfy --workflow FILE does the same for your own workflow file
hpc download comfy [PATH…]Copy the ComfyUI results (videos, images) from the cluster to this machine; --latest N takes the newest files, --to DIR chooses the folder; never deletes
hpc wait IDBlock until a job ends; succeed only if it completed
hpc doctorCheck tools, VPN and SSH access, Slurm and the project directory
hpc info IDCPU and memory efficiency of a finished job
hpc freeClasses with a free GPU slice right now

Jobs run preemptible by default; with an active booking, --booked selects the protected QoS. Preemption can stop a job at any time, so write checkpoints. See the README for the details.
